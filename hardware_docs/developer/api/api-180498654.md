# Obtain player list

Source: [api-180498654.md](../../api/api-180498654.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Discover cloud players and map trucks to player IDs.

## Useful facts

- **`GET /v2/player/list`** — Discover cloud players and map trucks to player IDs.
- Basic API permission. Sub-accounts are limited to their workgroup and its descendants. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Pagination uses `start` (default 0) and `count` (default 20, range 1–100); `name` filters the list.
- Results include player ID/name, synchronous/asynchronous type, serial number, firmware version, IP, last-online time and online status (`0` offline, `1` online). The serial number can be null for an unbound player.
- The HTTP response contains `total` and `rows`; no asynchronous callback is defined.

## App implications and unknowns

Store the cloud player ID separately from the hardware serial number. Paginate the fleet and allow unbound/offline devices; neither presence in the list nor online status proves that an advertisement played.
