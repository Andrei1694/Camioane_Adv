# Taurus third-generation quick start

Source: [Taurus-Quick-Start-Guide-3rd-Generation-V1.0.2.pdf](../Taurus-Quick-Start-Guide-3rd-Generation-V1.0.2.pdf) Version: V1.0.2 (filename).

**Audience:** Mobile, web, backend. **Use:** Identify the onboarding tools and network prerequisites.

## Useful facts

- ViPlex Handy runs on Android/iOS; ViPlex Express and NovaLCT are Windows tools. ([PDF p. 1, 02 Required Software; printed panel 1](../Taurus-Quick-Start-Guide-3rd-Generation-V1.0.2.pdf#page=1))
- A direct Ethernet connection uses the ViPlex Express DHCP service. On a router-based wired LAN, disable that service and obtain the computer address automatically. ([PDF p. 1, 03 Typical Connections; printed panel 2](../Taurus-Quick-Start-Guide-3rd-Generation-V1.0.2.pdf#page=1))
- Wi-Fi AP access uses the player hotspot, with the password printed on the SSID label. Wi-Fi STA through a router is available only on supported products and is configured through ViPlex Express. ([PDF p. 1, 03 Typical Connections; printed panel 2](../Taurus-Quick-Start-Guide-3rd-Generation-V1.0.2.pdf#page=1))
- Login precedes screen configuration, content publishing, firmware upgrades and cloud binding. The guide describes device discovery and distinguishes offline, available and logged-in states. ([PDF p. 1, 04 Login; printed panels 3-4](../Taurus-Quick-Start-Guide-3rd-Generation-V1.0.2.pdf#page=1))
- Device login and hotspot access are separate credentials. This guide’s device-login default differs from older manuals; it recommends changing the default. ([PDF p. 1, 04 Login; printed panel 3](../Taurus-Quick-Start-Guide-3rd-Generation-V1.0.2.pdf#page=1))

## App implications and unknowns

Use this for an operator setup checklist and support flow. It contains no discovery protocol, local-control endpoints or mobile SDK. Do not hardcode default passwords or SSID prefixes: those also differ across the supplied editions. The single artwork-only PDF sheet was reviewed visually; panel numbers identify its internal layout.
