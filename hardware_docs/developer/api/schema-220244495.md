# ANALOG_WEATHER - Basic Weather Component

Source: [schema-220244495.md](../../api/schema-220244495.md) - OpenAPI Specification → components.schemas.ANALOG_WEATHER - Basic Weather Component. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Configure the basic graphical weather widget.

## Useful facts

- **ANALOG_WEATHER - Basic Weather Component schema:** requires language, fixed location, relative size, duration, refresh interval and temperature unit.
- Languages listed are Chinese, English, Japanese, Spanish, French, Portuguese and Italian; Romanian is not listed.
- Refresh is milliseconds, with a schema minimum of 10,000 (10 seconds); duration is also milliseconds. Temperature `0` = Celsius, `1` = Fahrenheit.
- This is a widget, not an endpoint; [Common Solutions examples](api-180502121.md) demonstrate its `ANALOG_WEATHER` type.

## App implications and unknowns

Keep this distinct from simple WEATHER and ADVANCED_WEATHER. Confirm device support, weather coverage and available localization before adding it to the editor.
