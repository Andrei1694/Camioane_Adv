# Controller — basic information

Source: [api-181820142.md](../../api/api-181820142.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Read controller identity, software and health.

## Useful facts

- **`GET /v2/device-status-monitor/master-control/basics/{sn}`** — Read controller identity, software and health.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Query by device `sn`; fields include software version, MAC, Ethernet-port count, time zone and status (`true` normal, `false` abnormal).
- `signalSource` and `reportTime` return empty for the source’s “LCT590 and Mbox V1.3 or above” configurations.
- This is a direct HTTP response, not a push subscription. Monitoring requires VNNOX Care binding; availability depends on the installed device and reporting hardware.

- The status description uses boolean meanings, but its declared schema type is integer; confirm actual responses.

## App implications and unknowns

Support missing source and report timestamps. Keep this hardware health separate from the [cloud online status](api-180498661.md) and from media playback.
