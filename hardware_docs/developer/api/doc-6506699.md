# Weather widget

Source: [doc-6506699.md](../../api/doc-6506699.md) - Weather widget. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Find the simple-weather publishing example.

## Useful facts

- **Weather widget:** this example uses `type: WEATHER` inside [Common Solutions](api-180502121.md); it creates no weather-reading endpoint.
- The example supplies a fixed address/latitude/longitude, refresh period, Celsius/Fahrenheit setting, visible weather sections and percentage layout.
- The embedded schema is [Player Common Solution](schema-162442578.md); the dedicated [simple weather schema](schema-220236771.md) supplies constraints.
- The sample uses numeric `unitSymbol`, while the enclosing Common Solution schema types that field as string.

## App implications and unknowns

Weather is optional content, not a truck-location source. Replace all sample location values and confirm actual field types, weather availability and refresh behavior.
