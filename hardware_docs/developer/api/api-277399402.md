# Over-specification Detection Switching

Source: [api-277399402.md](../../api/api-277399402.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Enable or disable player over-specification detection.

## Useful facts

- **`POST /v2/player/immediateControl/over-specification-options`** — Enable or disable player over-specification detection.
- This page does not state a basic/advanced permission tier. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- The request contains `playerIds` and boolean `enable`.
- The response contains `success` and `fail`; no execution callback or detailed result semantics are supplied.
- This page gives no maximum batch size, firmware minimum or explicit permission tier.

## App implications and unknowns

Keep detection enabled unless there is a validated device-specific reason to change it. Disabling checks does not increase hardware decoding capacity; use the [program preflight API](api-277411236.md) for media feedback.
