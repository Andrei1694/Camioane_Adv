# Modules and cabinets — monitoring

Source: [api-188115020.md](../../api/api-188115020.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web. **Use:** Read module/cabinet configuration metadata.

## Useful facts

- **`GET /v2/device-status-monitor/module/monitor/{sn}`** — Read module/cabinet configuration metadata.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Query by device `sn`; response items describe dimensions, driver IC, decoder IC and scan count.
- This is a direct HTTP response, not a push subscription. Monitoring requires VNNOX Care binding; availability depends on the installed device and reporting hardware.
- No playback, publishing, editing or configuration-write capability is exposed here.

Keep this in a support view when available. The installer still supplies exact screen mapping and configuration backups.
