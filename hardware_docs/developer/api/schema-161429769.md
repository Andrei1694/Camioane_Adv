# Environmental Monitoring item

Source: [schema-161429769.md](../../api/schema-161429769.md) - OpenAPI Specification → components.schemas.Environmental Monitoring item. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Describe optional environmental readings on the player display.

## Useful facts

- **Environmental Monitoring item schema:** `RT_MEDIA` is published as a widget; it is not a telemetry endpoint.
- Fonts are limited to the listed player fonts; label/value/unit sizes are 9–256. Refresh and duration use milliseconds.
- Scrolling uses gear 1–10 or pixel value 10–500 according to `seedByPixelEnable`. The literal field spelling is part of the contract.
- Measurements have enable flags, labels and units. Temperature can be Celsius/Fahrenheit with compensation −50 to 50; pressure/wind units must match their numeric type.
- Wind direction labels must run North, Northeast, East, Southeast, South, Southwest, West, Northwest. See the source for every measurement key.
- The source inconsistently uses `STATIC`, `STATI` and `Scroll`/`SCROLL`; some unit descriptions are questionable (for example “sunshine duration” in W/m²).

## App implications and unknowns

Verify modes, units and sensor support before implementation. A comprehensive schema is not evidence that all truck sensors exist; parent endpoint permissions and asynchronous publishing apply.
