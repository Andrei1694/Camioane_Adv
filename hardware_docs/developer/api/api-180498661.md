# Obtaining Basic Player Information

Source: [api-180498661.md](../../api/api-180498661.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Read cloud online status and basic identity.

## Useful facts

- **`POST /v2/player/current/online-status`** — Read cloud online status and basic identity.
- Basic API permission. Sub-accounts are limited to their workgroup and its descendants. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- The described result is returned directly, without a callback: player ID, serial number, online status and last-online time.
- Despite the broad title/prose, the response schema does not supply the full runtime configuration; use [running status](api-186309730.md) for brightness, volume and clock.
- The request schema marks both `playerIds` and `playerSns` required, while their descriptions are ambiguous. The example instead supplies one identifier array or the other; confirm this schema/example conflict.

## App implications and unknowns

Confirm accepted identifier combinations before implementation. Do not infer playback, hardware health or a maximum batch size from this page.
