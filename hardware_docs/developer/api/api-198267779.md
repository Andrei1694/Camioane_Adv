# Brightness History

Source: [api-198267779.md](../../api/api-198267779.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web. **Use:** Read brightness adjustment history.

## Useful facts

- **`POST /v2/device-status-monitor/brightness/history`** — Read brightness adjustment history.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Maximum search span is 30 days. `startTime`/`endTime` are millisecond timestamps; query by device serial number.
- Pagination uses `currentPage` (default 1), `pageSize` (default 10) and `orderRule` (`asc`/`desc`). The response contains current page, totals and data.
- Adjustment types include manual `0`, scheduled `1`, automatic `2` and failed light-sensor read `5`; records include brightness percentage, result, time and time zone.
- The history is returned directly; no asynchronous export or callback is specified.

## App implications and unknowns

Show sensor-read failures distinctly from brightness levels. Confirm timestamp boundaries and data freshness; this history does not demonstrate media playback.
