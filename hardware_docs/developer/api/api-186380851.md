# Solution Change Notifications

Source: [api-186380851.md](../../api/api-186380851.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Register the endpoint labeled solution-change notifications.

## Useful facts

- **`POST /v2/notification-hooks/program-updates`** — Register the endpoint labeled solution-change notifications.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- The source requires Taurus V3.7.0 or later; up to 100 player IDs and `noticeUrl`.
- The immediate response contains successful player IDs, with later notification callbacks intended.
- Contradiction: the title/path say solution changes, but the description, callback name and fields all describe video-source changes (`videoSource`, player name and update time). No solution identifier is documented.

## App implications and unknowns

Treat the solution-change payload contract as unresolved. Obtain a corrected definition or device-verified payload before using this endpoint to claim a new campaign started; [download progress](api-180502121.md) is a different event.
