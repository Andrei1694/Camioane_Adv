# Taurus firmware V5.1.0

Source: [Taurus-Firmware-Release-Notes-V5.1.0.txt](../Taurus-Firmware-Release-Notes-V5.1.0.txt) - Supporting Software; New Features; Improvements. Version: V5.1.0 (2026-09-18).

**Audience:** Backend, web, mobile. **Use:** Identify firmware-dependent features and companion software.

## Useful facts

- The 2026-09-18 release requires NovaLCT V5.9.2+, ViPlex Express V4.1.1+, ViPlex Handy V6.0.0+ and VNNOX Care App V2.5.0+ (Supporting Software).
- Devices with default static addresses can be discovered and switched to dynamic addresses; the network connection status can be inspected (New Features / Improvements).
- Adds VNNOX Care monitoring V3.0, playback/device-operation alarm export, and abnormal alarms for webpages, streaming media and RSS (New Features).
- Adds playlist description/media/screenshot downloads and device diagnostic reports through ViPlex Express (New Features).
- Adds configuration import/export covering source, screen state, power, time sync, network, playback, topology and peripherals (New Features).
- Adds HDMI upscaling and mosaic changes; ultra-long-screen configuration and exact scaling behavior refer to separate guides (New Features / Improvements).
- Improves USB playback through transcoding, font management and player-authentication-based binding to VNNOX Care (Improvements).

## App implications and unknowns

Check the installed firmware before showing these capabilities. The family-wide note about converting a primary/backup Ethernet pair to 1.3 million pixels is not a new TB60 capacity specification. No new public endpoint or local SDK contract is supplied by this release file.
