# API Access Guide

Source: [doc-4696857.md](../../api/doc-4696857.md) - Supported Devices, Preparation, Access Procedure, Rate Limits and Business Process Example. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Establish NovaCloud access, authentication and request limits.

## Useful facts

- **Supported Devices / Preparation:** publishing covers TU/TB/T series; monitoring additionally covers MSD/MCTRL, V/VX and MBOX V1.3+. Bind publishing devices to VNNOX Media and monitoring devices to VNNOX Care; these are distinct prerequisites.
- **Access Procedure:** one AK/AS pair per user. Basic permissions are provided initially; full API permissions require enterprise authentication. The actual account permissions remain unknown.
- **Confirm the request address:** use HTTPS and the service domain supplied for the account’s region. Examples inconsistently use `open-us` and `openapi-us`; do not infer the production host from an example.
- **Prepare public request parameters / Generate a request signature:** headers are string `AppKey`, `Nonce`, `CurTime`, `CheckSum`. Nonce is 8–64 alphanumeric characters; UTC time is epoch seconds within 5 minutes of server time. Checksum is hexadecimal SHA-256 of `AppSecret + Nonce + CurTime`.
- **Assemble specific API request parameters:** GET business parameters are described as URL parameters; POST uses JSON. Individual exports contain inconsistencies such as a GET request body.
- **Rate Limits:** at most 15 calls/second and 1,500 calls/hour per IP; exceeding them returns 429.
- **Business Process Example:** the snapshot links external workflow images rather than storing their contents locally. The text provides the access contract; the images do not supply an offline local-control SDK.

## App implications and unknowns

Keep the secret and signing on the backend; web/mobile call the app backend. Budget calls across devices and services sharing an outbound IP. Empty `security: []` in the OpenAPI exports does not override this guide. Installed versions, region, account permissions and callback verification remain integration inputs.
