# Environmental Monitoring widget

Source: [doc-6507057.md](../../api/doc-6507057.md) - Environmental Monitoring widget. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Find the environmental-sensor widget publishing example.

## Useful facts

- **Environmental Monitoring widget:** demonstrates `RT_MEDIA` within [Common Solutions](api-180502121.md), with an embedded [Player Common Solution schema](schema-162442578.md).
- Labels cover temperature, humidity, light, air quality and other measurements, with refresh interval, units and display/scroll settings; use the [dedicated schema](schema-161429769.md).
- The example includes a literal line break inside the final wind-direction JSON string. It must be corrected before use as valid JSON.
- This page configures displayed measurements; it does not expose a telemetry-read API or prove that a sensor is installed.

## App implications and unknowns

Omit this from a basic ad editor unless the installation includes supported environmental sensors. Confirm the data source and units; do not infer hardware capability from the sample’s enabled fields.
