# Video Source Change Notifications

Source: [api-186379152.md](../../api/api-186379152.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Register notifications for internal/external video-source changes.

## Useful facts

- **`POST /v2/notification-hooks/video-source-updates`** — Register notifications for internal/external video-source changes.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Target up to 100 player IDs and provide `noticeUrl`. The immediate response lists successfully registered/sent player IDs.
- The callback includes `playerId`, player name, update time and `videoSource` (`0` internal, `1` external; the schema declares this field a string).
- No subscription deletion, expiry, retry policy, acknowledgement format or callback authentication is specified.

## App implications and unknowns

Use updates to explain external-source interruptions of app content. Confirm notification lifecycle and delivery reliability before depending on this as the only source of state.
