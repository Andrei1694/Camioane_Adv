# Obtaining Login URL

Source: [api-186409414.md](../../api/api-186409414.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Obtain a temporary URL for access to VNNOX.

## Useful facts

- **`POST /v2/integration/vnnox-access-url`** — Obtain a temporary URL for access to VNNOX.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Sub-users cannot call this interface. Supply the destination username and language (`zh-CN`, `en`, `jp`); choose `pro` (AD) or `lite` (Standard).
- The description defaults `sys` to AD when omitted, but the schema marks it required.
- Response `url` and `expire` (seconds) arrive directly; the example lifetime is not a guaranteed fixed duration.

## App implications and unknowns

Request links on the backend for an authorized app user and respect the returned expiry. Explicitly supply the subsystem and avoid treating the URL as a permanent bookmark.
