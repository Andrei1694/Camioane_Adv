# Solution widgets base

Source: [schema-161525226.md](../../api/schema-161525226.md) - OpenAPI Specification → components.schemas.Solution widgets base. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Reuse shared layout/media fields when composing solutions.

## Useful facts

- **Solution widgets base schema:** describes image, GIF, video, text, RSS, HTML, stream, window, weather, clock and environmental widget families; this is not an endpoint.
- Image/video widgets use MD5, byte size and a reachable URL; playback/animation durations are milliseconds. A meaningful name helps distinguish playback records.
- Layout coordinates and size are percentages; higher `zIndex` draws above lower layers. `BOX` windows require `mediaList`.
- Optional offline HTML uses a downloadable file with MD5/size. CSS and JavaScript must be inline; external CSS/JS cannot be downloaded for offline use.
- The generic required list includes media fields even for non-media types. Follow type-specific schemas and examples instead of assuming every widget has the same payload.

- `mediaList` items are typed strings here, while the publishing endpoint’s BOX example uses widget objects; confirm the accepted shape.

## App implications and unknowns

Validate each widget type separately and confirm player support. Offline HTML is labeled a custom function; it does not establish a general local web-app deployment interface.
