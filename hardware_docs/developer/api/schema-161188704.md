# Scheduled plan item

Source: [schema-161188704.md](../../api/schema-161188704.md) - OpenAPI Specification → components.schemas.Scheduled plan item. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Share date/time rules across scheduled player controls.

## Useful facts

- **Scheduled plan item schema:** requires `startDate`, `endDate` (`YYYY-MM-DD`) and `execTime` (`HH:MM:SS`).
- Execution follows the player’s local time, not the API server or app user’s time zone.
- `weekDays` uses Sunday `0` through Saturday `6`; missing or empty means every day within the plan’s date range.
- This is a reusable schema, not an endpoint. Action-specific fields, permissions, batch limits and clearing behavior come from the [scheduled control endpoints](api-285406451.md).

## App implications and unknowns

Use a common schedule editor with visible device time zone. Daylight-saving transitions, overlapping entries and date-boundary inclusivity are not resolved here.
