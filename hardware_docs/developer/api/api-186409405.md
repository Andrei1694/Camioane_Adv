# Obtaining User List

Source: [api-186409405.md](../../api/api-186409405.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web. **Use:** List cloud users and their accessible VNNOX subsystems.

## Useful facts

- **`GET /v2/integration/account/list`** — List cloud users and their accessible VNNOX subsystems.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Includes sub-users; exposes username, organization-administrator flag and subsystem permissions (`pro` = AD, `lite` = Standard).
- Returns data directly with no callback or paging contract.
- The schema models one object with string `sysPermissions`, while the example is an array of users with an array of permissions.

## App implications and unknowns

Confirm the collection types. Use these permissions for the vendor handoff; they are not the app’s own authorization model.
