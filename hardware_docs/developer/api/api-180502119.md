# Synchronous playback

Source: [api-180502119.md](../../api/api-180502119.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Enable or disable synchronous playback.

## Useful facts

- **`POST /v2/player/real-time-control/simulcast`** — Enable or disable synchronous playback.
- Advanced API permission is required. Sub-accounts are limited to their workgroup and its descendants. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Maximum 100 player IDs; `option` is `0` off or `1` on.
- The response separates `success` and `fail` player IDs; successful sending does not establish device execution. No completion callback is specified here.
- This endpoint exposes the switch; it does not specify compatible device groupings, content limits or clock setup.

## App implications and unknowns

Apply the separate [synchronization prerequisites](../Taurus-Synchronous-Playback-Implementation-Instructions-V1.6.7.md). A successful command is not proof that multiple truck screens are synchronized.
