# Hand drawn digital clock

Source: [schema-156550829.md](../../api/schema-156550829.md) - OpenAPI Specification → components.schemas.Hand drawn digital clock. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Implement an optional clock widget with explicit time formatting.

## Useful facts

- **Hand drawn digital clock schema:** used by `DRAWN_DIGITAL_CLOCK` in [Common Solutions](api-180502121.md); there is no separate endpoint.
- Uses IANA `zone` plus `gmt`, a formatting template, seven weekday labels, AM/PM labels and font fallback array. Tokens distinguish 24-hour `$HH` from 12-hour `$hh`; detailed formatting stays in the source.
- Layout is percentage based; greater `zIndex` places the widget above lower layers. Font size and shadow dimensions are pixels.
- The schema says weekday labels run Monday–Sunday, while the [example](doc-6506467.md) starts Sunday. Its generic `type` description omits the clock type, and font-style casing differs from the example.

## App implications and unknowns

Resolve those inconsistencies and time-zone/daylight-saving behavior on the actual player before exposing this optional content. Follow parent publishing permissions and callbacks.
