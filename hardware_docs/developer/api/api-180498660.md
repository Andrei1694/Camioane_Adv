# Screen Power

Source: [api-180498660.md](../../api/api-180498660.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Switch configured screen power outputs.

## Useful facts

- **`POST /v2/player/real-time-control/power`** — Switch configured screen power outputs.
- Advanced API permission is required. Sub-accounts are limited to their workgroup and its descendants. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Maximum 100 player IDs per request.
- `option`: `0` power off, `1` power on. Configure relays with the “Screen Power” label in NovaLCT/ViPlex before using this API.
- The response separates `success` and `fail` player IDs; successful sending does not establish device execution. No completion callback is specified here.

## App implications and unknowns

Enable this action only after the supplier confirms relay configuration and wiring. [Power status](api-186309730.md) uses the opposite numeric convention (`0` on, `1` off); do not reuse one enum.
