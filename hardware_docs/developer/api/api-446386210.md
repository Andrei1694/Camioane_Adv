# Add Player

Source: [api-446386210.md](../../api/api-446386210.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Add players to a cloud account using serial numbers.

## Useful facts

- **`POST /v2/player/iot-add`** — Add players to a cloud account using serial numbers.
- This page does not state a basic/advanced permission tier. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Only the primary account may call this endpoint; at most 100 serial numbers per request.
- Added devices enter a pending-activation list and move to the account’s player list after connecting to the network.
- Returns `success` and `fail` serial-number sets; no activation callback is documented.

- The response schema is flat arrays of strings, but the example wraps `success`/`fail` under `data` and returns success objects with `snCode`, `snName` and `date`. Confirm this response shape.

## App implications and unknowns

Represent onboarding as added/pending and then activated. Reconcile with the [player list](api-180498654.md); the page does not explain existing-account transfers, unbinding or ownership conflicts.
