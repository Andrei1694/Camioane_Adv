# NTP Time Synchronization

Source: [api-180502118.md](../../api/api-180502118.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Enable or disable NTP clock synchronization.

## Useful facts

- **`POST /v2/player/real-time-control/ntp`** — Enable or disable NTP clock synchronization.
- Advanced API permission is required. Sub-accounts are limited to their workgroup and its descendants. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- The request requires `playerIds`, `enable` and NTP `server`; at most 100 players can be targeted.
- An RF slave cannot use NTP synchronization until RF synchronization is disabled.
- The response separates `success` and `fail` player IDs; successful sending does not establish device execution. No completion callback is specified here.

## App implications and unknowns

Choose a reachable NTP server and confirm RF roles. Clock synchronization is one prerequisite of [synchronous playback](../Taurus-Synchronous-Playback-Implementation-Instructions-V1.6.7.md); it does not itself synchronize playlists.
