# Common HTTP Status Codes

Source: [doc-4696860.md](../../api/doc-4696860.md) - Common HTTP Status Codes. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Interpret shared HTTP failures without confusing them with player results.

## Useful facts

- **Common HTTP Status Codes:** 400 is invalid syntax/parameters, 401 authentication failure, 403 missing permission (including enterprise-authentication issues), and 406 parameter validation failure.
- 429 means rate limiting; use the [Access Guide limits](doc-4696857.md).
- 500/502/503/504 are server or gateway failures; 501 is an unsupported function.
- 200 means the request succeeded at HTTP level; endpoint-specific bodies and callbacks still determine per-player or task outcomes.

## App implications and unknowns

Present authentication, permission, validation and service failures separately. Decide retries using operation semantics; a repeated command or export is not documented as idempotent. Detailed error bodies belong to each source endpoint.
