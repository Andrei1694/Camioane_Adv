# Input source — monitoring

Source: [api-188114676.md](../../api/api-188114676.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web. **Use:** Read input-source computer resource information.

## Useful facts

- **`GET /v2/device-status-monitor/input-source/monitor/{sn}`** — Read input-source computer resource information.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Query by device `sn`; returns drive capacity/usage (GB), CPU, RAM and system information.
- The `system` field is documented as empty for “LCT590 and Mbox V1.3 or above”.
- This is a direct HTTP response, not a push subscription. Monitoring requires VNNOX Care binding; availability depends on the installed device and reporting hardware.

## App implications and unknowns

This is mainly relevant to installations using a monitored PC/input source. Do not present it as guaranteed TB60 internal storage or treat it as source-switch control.
