# Hand-drawn clock widget

Source: [doc-6506467.md](../../api/doc-6506467.md) - Hand-drawn clock widget. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Find the publishing example for a drawn digital clock.

## Useful facts

- **Hand-drawn clock widget:** this is a payload example for [Common Solutions](api-180502121.md), not a separate endpoint; `type` is `DRAWN_DIGITAL_CLOCK`.
- The example supplies time zone/GMT, formatted date/time, weekday and AM/PM labels, font fallbacks and percentage-based layout.
- The embedded schema ID 162442578 resolves to [Player Common Solution](schema-162442578.md); the dedicated [clock schema](schema-156550829.md) explains the fields.
- The example orders weekday labels Sunday first, while the dedicated schema says Monday first. Its `fontStyle` casing also differs from the uppercase names in the schema.

## App implications and unknowns

Optional for the app’s content editor. Verify weekday order, font-style values and daylight-saving behavior before offering clocks; publishing callbacks follow Common Solutions.
