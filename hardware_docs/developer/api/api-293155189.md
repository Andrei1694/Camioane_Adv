# Camera configuration

Source: [api-293155189.md](../../api/api-293155189.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web. **Use:** Change an existing monitoring camera configuration.

## Useful facts

- **`PUT /v2/device-status-monitor/camera`** — Change an existing monitoring camera configuration.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Requires camera `id`, `name`, device `sid` and `enable` (`1` on, `0` off).
- This is a PUT on the same path used by POST for [camera images](api-293155525.md). It is not a player screenshot request.
- The page has no detailed success body or asynchronous completion callback; it does not describe adding camera hardware or credentials.

## App implications and unknowns

Only expose this when the installation already has a supported camera and Care configuration. Confirm result/error behavior and camera availability before enabling the control.
