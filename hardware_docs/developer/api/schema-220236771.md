# WEATHER - Simple Weather Component

Source: [schema-220236771.md](../../api/schema-220236771.md) - OpenAPI Specification → components.schemas.WEATHER - Simple Weather Component. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Configure the simple weather widget.

## Useful facts

- **WEATHER - Simple Weather Component schema:** requires location address/coordinates, size, duration, refresh period and presentation controls.
- Duration/refresh values use milliseconds. Relative width/height interact with base layout; the source suggests increasing them if content is clipped.
- Temperature `0` = Celsius, `1` = Fahrenheit. `unitSymbol` may be `0` or `1` for Celsius but must be `1` for Fahrenheit.
- Controls select conditions, temperatures, wind, humidity and one-line display; this is content for [Common Solutions](api-180502121.md), not a weather or GPS API.
- Both this schema and the parent schema type `unitSymbol` as string, while publishing examples supply a number; confirm the accepted type.

## App implications and unknowns

Do not assume automatic truck-location tracking. Confirm weather data coverage and offline behavior; the page states no minimum refresh interval or firmware requirement.
