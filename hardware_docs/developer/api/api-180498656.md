# Volume Adjustment

Source: [api-180498656.md](../../api/api-180498656.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Set player volume immediately.

## Useful facts

- **`POST /v2/player/real-time-control/volume`** — Set player volume immediately.
- Advanced API permission is required. Sub-accounts are limited to their workgroup and its descendants. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Maximum 100 player IDs per request.
- `value` is a volume percentage from 0 to 100.
- The response separates `success` and `fail` player IDs; successful sending does not establish device execution. No completion callback is specified here.

## App implications and unknowns

Expose volume only where the truck installation uses audio. Use [running status](api-186309730.md) for confirmation.
