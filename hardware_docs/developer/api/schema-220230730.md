# Text component

Source: [schema-220230730.md](../../api/schema-220230730.md) - OpenAPI Specification → components.schemas.Text component. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Support formatted text with static, scrolling or paged display.

## Useful facts

- **Text component schema:** used for text publishing (see `ARCH_TEXT` examples in [Common Solutions](api-180502121.md)); no separate API.
- `STATIC` displays only the first screen if text overflows. `SCROLL` and `PAGE_SWITCH` use their corresponding attribute objects.
- Scrolling supports left/up directions and speed 1–10; page dwell time is milliseconds.
- Text is an array of lines and styled spans, with font size 9–256, colors and alignment. Only the listed device fonts are documented; fallback to supported Chinese font names is mentioned.
- The top-level required list includes both scroll and page attributes although descriptions make them mode dependent; color wording also says “16-digit” despite hex examples.

## App implications and unknowns

Prevent silent truncation in static mode and confirm conditional-field/color behavior on the player. Do not assume the app’s web fonts are installed on the device.
