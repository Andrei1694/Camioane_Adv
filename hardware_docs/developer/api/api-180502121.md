# Common Solutions

Source: [api-180502121.md](../../api/api-180502121.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Publish a normal multi-page solution.

## Useful facts

- **`POST /v2/player/program/normal`** — Publish a normal multi-page solution.
- Advanced API permission is required. Sub-accounts are limited to their workgroup and its descendants. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- The description supports Taurus versions later than 2.0.0; maximum 100 player IDs per request.
- Program/page schedules intersect when both are set; an empty schedule loops continuously. Weekday numbers run Sunday `0` to Saturday `6`.
- Use the [Player Common Solution schema](schema-162442578.md) and widget schemas for fields. Image/video content requires lowercase MD5, byte size, valid URL and duration in milliseconds; name widgets to distinguish playback records.
- `success`/`fail` indicate sending results. Optional `noticeUrl` reports download progress and must respond within 3 seconds.
- The callback uses the literal key `precess` (0–1), plus `status`: `0` normal, `1001` download failure/MD5 mismatch, `1002` media beyond specification; see the source `noticeUrl` description and callback example.

- `repeatCount` allows 1–100 repeats per page. Page-level `weekDays` is typed string despite the array examples; the linked schema note records this conflict.

## App implications and unknowns

Track publishing, downloading and actual playback separately. Validate media against the installed device; this endpoint does not promise the automatic transcoding shown in vendor software. Confirm offline/retry behavior and callback trust with the supplier.
