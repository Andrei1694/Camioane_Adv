# RSS component

Source: [schema-220235090.md](../../api/schema-220235090.md) - OpenAPI Specification → components.schemas.RSS component. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Configure an RSS feed widget.

## Useful facts

- **RSS component schema:** used for `SIMPLE_RSS` in [Common Solutions](api-180502121.md); the base widget supplies its feed URL and layout.
- `updatePeriod` is milliseconds with a minimum of 10,000 (10 seconds).
- Select paged or scrolling display; left/up scrolling speed is 1–10 and page dwell time uses milliseconds.
- Title, publication time, body and optional body images have separate controls; device font availability remains limited to the listed fonts.
- Both scroll and page attribute objects are marked required in the schema despite mode-dependent descriptions.

## App implications and unknowns

Treat RSS as network-dependent optional content. Confirm feed compatibility, caching/offline behavior and the conditional payload; refreshing RSS is not a playback-report callback.
