# Video Source Switching

Source: [api-180498657.md](../../api/api-180498657.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Switch between internal playback and an external video source.

## Useful facts

- **`POST /v2/player/real-time-control/video-source`** — Switch between internal playback and an external video source.
- Advanced API permission is required. Sub-accounts are limited to their workgroup and its descendants. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Maximum 100 player IDs per request.
- `source`: `0` internal, `1` external.
- The response separates `success` and `fail` player IDs; successful sending does not establish device execution. No completion callback is specified here.

## App implications and unknowns

Switching to an external source can interrupt the app playlist. Confirm the installed input and current state; [source notifications](api-186379152.md) can report changes.
