# Receiving cards — basic information

Source: [api-181820138.md](../../api/api-181820138.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Identify receiving cards attached to a device.

## Useful facts

- **`GET /v2/device-status-monitor/receiving-card/basics/{sn}`** — Identify receiving cards attached to a device.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Query by device `sn`; the result lists card FPGA/MCU versions, model, position and serial number.
- This is a direct HTTP response, not a push subscription. Monitoring requires VNNOX Care binding; availability depends on the installed device and reporting hardware.
- Positions identify locations within the screen hardware; use the [location-code notes](doc-4696871.md).

## App implications and unknowns

Use this for support inventory and compatibility checks. It does not supply truck GPS coordinates or configure receiving cards.
