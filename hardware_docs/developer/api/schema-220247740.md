# ADVANCED_WEATHER - Advanced Weather Component

Source: [schema-220247740.md](../../api/schema-220247740.md) - OpenAPI Specification → components.schemas.ADVANCED_WEATHER - Advanced Weather Component. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Configure the advanced weather widget and its regional limits.

## Useful facts

- **ADVANCED_WEATHER - Advanced Weather Component schema:** adds four display styles, per-page duration and selectable information sections to fixed-location weather.
- Overall duration, page duration and refresh interval are milliseconds. Unlike the basic-weather schema, no numeric minimum refresh interval is specified here.
- Air-quality and living-index sections are documented as China-region only. Other switches cover basic weather, comfort, wind/pressure and sunrise/sunset.
- Languages are Chinese, English, Japanese, Spanish, French, Portuguese and Italian; temperature `0` = Celsius, `1` = Fahrenheit.
- The [wrapper page](doc-7691712.md) incorrectly labels this embedded schema ANALOG_WEATHER / Basic. The schema and publishing example use ADVANCED_WEATHER.

- `module` is declared a string, while the publishing example supplies a number. Verify its actual type.

## App implications and unknowns

For deployments outside China, omit China-only sections and confirm coverage and firmware support. This optional widget follows normal publishing permissions/callbacks; it does not expose forecast data to the app.
