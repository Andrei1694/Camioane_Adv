# The camera monitors the aggregated information

Source: [api-293155525.md](../../api/api-293155525.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Read monitoring-camera images for selected screens.

## Useful facts

- **`POST /v2/device-status-monitor/camera`** — Read monitoring-camera images for selected screens.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Requires `sidList` and requested thumbnail width/height; no batch or dimension maximum is stated.
- Returns image/thumbnail URL lists and camera metadata directly. `noCameraSidList` identifies screens without cameras.
- Camera flags distinguish enablement, generated directories and configuration. No live-video stream, image timestamp, URL lifetime or refresh guarantee is documented.

## App implications and unknowns

Treat this as camera imagery with unknown freshness until confirmed. Use [player screenshots](api-180502120.md) for rendered content; installed cameras remain an optional dependency.
