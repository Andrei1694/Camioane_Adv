# Single-Page Emergency Insertion Solutions

Source: [api-180502122.md](../../api/api-180502122.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Insert an emergency single-page solution.

## Useful facts

- **`POST /v2/player/emergency-program/page`** — Insert an emergency single-page solution.
- Advanced API permission is required. Sub-accounts are limited to their workgroup and its descendants. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Maximum 100 players. `spotsType` selects `IMMEDIATELY` or `TIMING`; `normalProgramStatus` selects `NORMAL` or `PAUSE` for the normal solution.
- Insertion duration is in milliseconds and capped at 24 hours; scheduled insertion adds `timingTime`, for example `12:00:00`.
- The documented media types are `PICTURE`, `VIDEO` and `ARCH_TEXT`. Detailed widgets and insertion attributes remain in the source request schema.
- The source calls this single-page insertion, but models `page` as an array while its example supplies one object. The response reports `success`/`fail` sending results and specifies no completion callback.

## App implications and unknowns

Model emergency insertion separately from the regular schedule and offer [cancellation](api-180502123.md). Confirm the array shape, time-zone interpretation and normal-playback resume behavior on the target firmware.
