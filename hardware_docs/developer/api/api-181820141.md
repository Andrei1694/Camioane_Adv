# Screen — monitoring

Source: [api-181820141.md](../../api/api-181820141.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Read screen dimensions and brightness.

## Useful facts

- **`GET /v2/device-status-monitor/screen/monitor/{sn}`** — Read screen dimensions and brightness.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Query by device `sn`; returns LED/LCD type, width, height, screen brightness and ambient brightness.
- `envBrightness = -1` means the ambient brightness was not obtained; it is not a valid light level.
- This is a direct HTTP response, not a push subscription. Monitoring requires VNNOX Care binding; availability depends on the installed device and reporting hardware.

## App implications and unknowns

Use this as reported screen context. Ambient sensing hardware and refresh cadence remain unknown; do not derive media-decoding limits from screen dimensions.
