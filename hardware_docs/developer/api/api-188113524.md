# Smart modules — monitoring

Source: [api-188113524.md](../../api/api-188113524.md) - OpenAPI Specification: operation description, request/response schemas and examples. Unversioned API snapshot retrieved 2026-11-10.

**Audience:** Backend, web, mobile. **Use:** Read smart-module health and attached module metadata.

## Useful facts

- **`GET /v2/device-status-monitor/smart-module/monitor/{sn}`** — Read smart-module health and attached module metadata.
- Advanced API permission is required. Apply the [Access Guide](doc-4696857.md) authentication and account prerequisites.
- Query by device `sn`; smart-module fields include normal/abnormal state, flat-cable state, runtime, temperature, voltage and position.
- An additional `modules` list describes module/cabinet dimensions, driver/decoder ICs and scan count.
- This is a direct HTTP response, not a push subscription. Monitoring requires VNNOX Care binding; availability depends on the installed device and reporting hardware.

## App implications and unknowns

Useful for maintenance only if smart-module reporting is available. Runtime is not advertising playback time; this page leaves its unit unspecified, while the [aggregate schema](api-289009793.md) says minutes.
